# Code of Conduct

Folder Watch aims to be a welcoming, practical open-source project.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while staying precise about technical claims.
- Give actionable feedback about code and behavior, not people.
- Respect different experience levels, backgrounds, identities, and working styles.
- Protect private project names, media, file paths, and client information.
- Credit contributors and sources accurately.
- Accept maintainer decisions about scope, safety, and release readiness.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks
- Sexualized language or unwanted attention
- Publishing another person's private information
- Deliberately misleading bug reports or compatibility claims
- Pressuring contributors to disclose private project files
- Repeatedly disrupting issues, pull requests, or discussions
- Introducing telemetry, credential collection, destructive file behavior, or hidden network access without explicit public review

## Enforcement

Maintainers may edit, hide, lock, or remove contributions that violate this code. Repeated or serious violations may result in a temporary or permanent ban from project spaces.

Report conduct concerns privately through the maintainer contact listed in [SECURITY.md](SECURITY.md). Include links or screenshots when possible. Reports will be reviewed in good faith and handled with appropriate confidentiality.

## Scope

This code applies in the repository, issue tracker, pull requests, release discussions, and other spaces where someone is representing Folder Watch.
